# Influence Maximization (IM) — Research Log

> Focus: Influence Maximization as a Graph Inverse / Graph Learning Problem
> Goal: Identify SOTA methods, datasets, and data formats for ML-based IM

---

## 1. Problem Formulation

**Influence Maximization (IM):** Given a social network graph `G = (V, E)` with edge propagation probabilities, select a seed set `S ⊆ V` of `k` nodes to maximize expected influence spread `σ(S)` — i.e., the expected number of nodes eventually activated under a diffusion model.

**Formally:**
```
S* = argmax_{S ⊆ V, |S| ≤ k} σ(S, G; θ)
```
- `V` = nodes (users), `E` = edges (social connections)
- `k` = seed budget (hyperparameter)
- `θ` = diffusion model parameters (edge probabilities)
- `σ(S)` = expected spread (computed via Monte Carlo or learned surrogate)

**NP-hard** — Kempe et al. (2003) proved this. The greedy (1 - 1/e) approximation via submodularity is the classical baseline (CELF).

---

## 2. Diffusion Models (Simulation Backbone)

### Independent Cascade (IC)
- When node `u` becomes active, it has **one chance** to activate each inactive neighbor `v` with probability `p(u,v)` (edge weight)
- Activations are independent across edges
- Most widely used in ML papers

### Linear Threshold (LT)
- Each node `v` has a threshold `θ_v ~ Uniform[0,1]`
- Node activates when `∑_{u∈N(v), u active} w(u,v) ≥ θ_v`
- Captures conformist/peer-pressure dynamics

### Susceptible-Infectious-Susceptible (SIS)
- Used in DeepIM — nodes can recover and be re-infected
- Models recurring phenomena (e.g., rumors, seasonal trends)

**Edge probabilities are either:**
- Set uniformly (e.g., `p = 0.01` or `p = 1/in-degree(v)`)
- Learned from observed cascade data (data-driven approach)

## 4. Data Format — What the Data Looks Like

### 4.1 Graph Data (Input)
```
Node features:   degree, PageRank, k-core number, betweenness (or learned embeddings)
Edge features:   propagation probability p(u,v), edge weight
Graph format:    adjacency list or sparse adjacency matrix
```

### 4.2 Cascade / Diffusion Trace Data
Generated by running IC/LT simulations from random seed sets:

```
A single cascade:
  - Seed set: [v1, v3, v7]          # initial active nodes (input)
  - Activation sequence:            # timestep-ordered events
      t=0: {v1, v3, v7}
      t=1: {v2, v9, v12}            # activated by v1, v3
      t=2: {v5, v15}                # activated by v9
      t=3: {}                       # no new activations → cascade stops
  - Final active set: {v1,v2,v3,v5,v7,v9,v12,v15}
  - Influence spread: 8
```

**Cascade dataset format (IMINFECTOR style):**
```
cascade_id | initiator_node | participating_nodes | cascade_size | timestamps
```

**Real cascade data (Weibo, Digg):**
- Retweet/repost chains with timestamps
- Node = user, edge = retweet relationship
- Cascade = one viral post's propagation tree

### 4.3 Seed Set Label Data (Supervised Approaches)
```
Input:  graph G + budget k
Output: binary vector x ∈ {0,1}^|V|  where x_i = 1 if v_i is seed
```
Labels generated by running expensive greedy/IMM on training graphs.

### 4.4 Continuous Latent Space (DeepIM / REM)
```
Discrete seed set x → encoder → z ∈ R^d (Gaussian latent)
Optimize z in continuous space → decoder → x̂ (soft seed probabilities)
```

## 5. Methods — Chronological Taxonomy

### 5.1 Classical (Pre-ML) Baselines

| Method | Year | Approach | Complexity |
|--------|------|----------|------------|
| **Greedy + MC** | 2003 | Marginal gain, Monte Carlo simulation | O(k·n·R·m) — very slow |
| **CELF** | 2007 | Lazy evaluation of marginal gains | 700× speedup over greedy |
| **Degree/PageRank** | - | Heuristics, no simulation | O(n log n) |
| **IMM** | 2015 | Reverse influence sampling (RIS) | Near-linear, approx guarantee |
| **OPIM-C** | 2018 | Online processing RIS | Near-optimal |
| **SubSIM** | 2021 | Sublinear time RIS | Sub-linear in n |

---

### 5.2 ML/DL Methods — Evolution

#### Tier 1: Early Learning-Based (2019–2020)

**IMINFECTOR** (2019) — `arxiv:1904.08804`
- **Approach:** Learn from real cascade data (no diffusion model needed)
- **Architecture:** Multi-task neural network — two tasks:
  1. Classification: which nodes will cascade reach?
  2. Regression: predict cascade size from initiator
- **Embeddings:** "Influencer vectors" (origin) + "Susceptible vectors" (target)
- **Input:** Cascade sequences (node sequences from real diffusion events)
- **Output:** Node embeddings → rank by influencer capacity → greedy seed selection
- **Datasets:** Digg (279K), MS Academic (1.4M), Weibo (1.2M)
- **Key strength:** Model-agnostic (no IC/LT assumption), learns from real cascades
- **Limitation:** Doesn't optimize globally, no RL component

**GCOMB** (2020) — Manchanda et al.
- **Approach:** Phase-wise mix of supervised + RL (Q-learning)
- **Architecture:** GCN for node quality prediction + Q-learning for combinatorial optimization
- **Stage 1 (supervised):** GCN scores individual nodes — prunes low-quality nodes
- **Stage 2 (RL):** Q-network picks seed set from remaining candidates
- **Input:** Graph + k budget
- **Output:** Seed set selected greedily by Q-values
- **Datasets:** NetHEPT, synthetic ER/BA graphs
- **Key strength:** Pruning enhances scalability, focuses compute on promising nodes

---

#### Tier 2: DRL + GNN Combinations (2021–2022)

**S2V-DQN for IM** — Chen et al. adaptation
- **Approach:** Structure2Vec embeddings + Deep Q-Network
- **Architecture:** Graph embedding via S2V → DQN for sequential node selection
- **Training:** On small random graphs, tested on larger ones
- **Limitation:** Doesn't generalize well; GCOMB and ToupleGDD outperform it

**GLIE** (2021) — `arxiv:2108.04623`
- **Approach:** GNN learns theoretical upper bound on influence spread
- **Architecture:** GLIE (Graph-based Local Influence Estimator) for influence estimation
- **Key idea:** Replace expensive MC simulations with learned estimator
- **Inductive:** Train on ≤300 node graphs, test on millions of nodes
- **Datasets:** Scales from tiny training graphs to million-node test graphs
- **Strength:** Most promising time efficiency + influence quality balance (at the time)

**ToupleGDD** (2022) — `arxiv:2210.07500`
- **Approach:** Three coupled GNNs + Double DQN
- **Architecture:**
  - GNN-1: Graph structure embedding
  - GNN-2: Current seed set state embedding
  - GNN-3: Node utility estimation
  - Double DQN: Learns Q-function for node selection
- **Training:** Small random graphs (ER/BA/WS), generalizes to large real-world graphs
- **Attention mechanism:** Across the three coupled GNNs
- **Input:** Graph G, current partial seed set
- **Output:** Next node to add to seed set (sequential selection)
- **Datasets:** Synthetic + multiple real-world networks, various budgets k
- **Results:** Close to IMM, better than OPIM-C and S2V-DQN
- **Strength:** Generalizability across graph types and seed budgets

---

#### Tier 3: Generative + Inverse Problem Approaches (2023) — **CURRENT SOTA**

**PIANO / DeepIM** (ICML 2023) — Ling et al. — `arxiv:2305.02200`
> **This is the paper you linked.**

- **Framework name:** DeepIM (Deep Influence Maximization)
- **Core novelty:** End-to-end generative approach — embeds discrete seed set into continuous latent space
- **Two-phase architecture:**
  1. **Learning phase:** VAE-style autoencoder learns `p(x)` — distribution over seed sets + GNN-based differentiable diffusion model
  2. **Inference phase:** Optimize latent `z` to find best seed set; decode → `x̂`
- **Diffusion models supported:** IC, LT, SIS
- **GNN diffusion model properties enforced:**
  - Score monotonicity (adding seeds can't decrease spread)
  - Infection monotonicity (more seeds → more coverage)
- **Lightweight variant:** DeepIM_s (student model) — 90% faster inference
- **Node-centrality constraints:** Supports cardinality + degree-based budget constraints
- **Datasets:** Cora-ML, Jazz, Power Grid, Network Science, Digg, Weibo, Synthetic
- **Results vs. baselines:**
  ```
  Dataset      | PIANO  | ToupleGDD | DeepIM
  -------------|--------|-----------|-------
  (one graph)  |  69.8  |   70.9    |  94.1   ← 30%+ improvement
  Jazz (LT)    |  -     |   -       | +200% over ToupleGDD
  ```
- **Generalization:** Works across unseen graphs with different structure

**FIM** (WWW 2024) — Huang et al. — `arxiv:2403.02867`
- **Approach:** Scalable continuous-time diffusion framework
- **Type:** Inverse problem — infer network from cascades + estimate influence
- **Input:** Diffusion cascades (temporal traces of information spread)
- **Output:** Inferred network structure + influence estimates
- **Key:** Models diffusion as continuous-time dynamical system (not discrete IC/LT steps)
- **Advantage over IC/LT:** More realistic for real temporal data
- **Advanced sampling technique** for efficiency
- **Outperforms NMF** on network inference + influence estimation

---

#### Tier 4: 2025 — Multiplex and VAE-RL Hybrids

**REM** (2025) — `arxiv:2501.00779`
- **Problem:** Multiplex Influence Maximization (MIM) — multi-layer networks
- **Architecture:**
  - **Seed2Vec:** VAE maps discrete seed set → continuous latent space z ~ N(μ,σ²)
  - **RL policy:** Treats generative model as policy, optimizes seed sets via RL rewards
  - Multi-expert routing for different network layers
- **Input:** Multiplex graph (multiple edge-type layers), budget k
- **Output:** Seed set maximizing influence across all layers
- **Datasets:** Cora-ML, Celegans, Arabidopsis, NYClimateMarch2014 (102K), ParisAttack2015 (1.9M)
- **Results:** 10-15% higher spread + 10-20% faster inference vs. MIM-Reasoner (previous SOTA)
- **Status:** Current SOTA for multiplex IM (Jan 2025)

**Topic-Aware IM with DRL + GAT** (2025) — Springer DAMI
- Combines GAT (Graph Attention Networks) + DRL for topic-specific influence
- Uses graph magnetic Laplacian for positional encoding
- Targets heterogeneous networks (DBLP: DM, ML, NLP subgraphs)

## 7. Two Paradigms: Input→Output vs. Timestep Diffusion

### Paradigm A: Direct Input→Output (Seed Set Prediction)
```
Input:  Graph G + budget k
Output: Binary vector x ∈ {0,1}^|V|
```
- Methods: GCOMB, ToupleGDD, GLIE, DeepIM
- Training signal: labeled seed sets from IMM/greedy on small graphs, or RL reward = influence spread
- Faster inference, more scalable
- **Most current SOTA methods use this paradigm**

### Paradigm B: Timestep Diffusion (Cascade Simulation)
```
Input:  Graph G + seed set x_0
State:  Active set A_t at each timestep t
Output: Final active set A_T (or spread size σ)
```
- Used internally by DeepIM's GNN diffusion model (differentiable IC/LT simulator)
- FIM uses continuous-time version of this
- Allows end-to-end gradient flow through diffusion process
- Cascade learning: IMINFECTOR, Inf2vec learn from these sequences directly

### Paradigm C: Inverse Problem (Learn from Cascades → Find Seeds)
```
Input:  Observed cascade traces C = {c_1, ..., c_m}
Output: Node embeddings → high-influence seeds
```
- Methods: IMINFECTOR, FIM, HIM (hyperbolic)
- No explicit diffusion model needed — learned from data
- Works with real social media data (retweets, reshares)

## 9. What Data to Use for Experiments

### Recommended Standard Setup

**Small/medium graphs (model development + ablation):**
- Cora-ML (2.8K nodes) — well-studied, citation network
- Jazz (198 nodes) — small, good for LT model tests
- Network Science (1.5K nodes)
- Power Grid (4.9K nodes)

**Large-scale (scalability tests):**
- Digg (279K nodes, 1.1M edges)
- Weibo (2.25M nodes, 225M edges)
- NetHEPT (15K nodes) — standard IM benchmark

**Synthetic (training generalization):**
- ER graphs: G(n, p) with n ∈ {100–500}, p ∈ {0.01–0.1}
- BA graphs: m=2–5 edges per new node
- WS graphs: k=4–10 neighbors, p=0.1 rewiring prob

**Edge probability assignment:**
```python
# Common practice for IC model:
p(u, v) = 1 / in_degree(v)    # weighted cascade model
# OR
p(u, v) = 0.01                # uniform (weak influence)
# OR learned from cascade data
```

**Cascade data generation for training:**
```python
# For each training graph:
for seed_set in random_seed_sets:
    cascade = simulate_IC(graph, seed_set, n_simulations=1000)
    spread = mean(cascade.spread)  # training label
```
